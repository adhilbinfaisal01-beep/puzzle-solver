How it works

Uninformed

BFS finds the shortest path but stores every level. DFS is cheap per step yet returns very long paths. UCS equals BFS for unit costs. IDDFS trades repeated work for low memory.

Informed

Greedy follows h(n) only – very fast, not optimal. A* orders nodes by f = g + h and is optimal with an admissible heuristic.

Heuristics

Misplaced tiles, Manhattan distance, and Manhattan + linear conflict. Each is admissible; stronger ones prune far more of the search space.

Benchmark results

Python implementation, 40 random solvable puzzles, mean per puzzle. Greedy is the only method returning non-optimal paths.

Hardest 8-puzzle instance (31 moves, 867254301): BFS expanded 181,347 nodes; A* Misplaced 143,840; A* Manhattan 20,291; A* Linear Conflict 12,293. Greedy needed only 100 expansions but returned a 47-move path; IDDFS hit the 1.5M-node cap.

About the project

The project builds a modular puzzle solver – state-space model, solvability check, search controller, heuristic module and metrics collector – and compares eight search strategies on solution quality, nodes expanded, memory (frontier size) and time. Solvability uses inversion parity: a state is solvable only if the number of inversions is even.

Future scope: 15-puzzle with IDA*, pattern databases, a web API, and visual search-tree playback.
